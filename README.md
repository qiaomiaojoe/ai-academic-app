# AI学术工作台 · 本地软件

乔淼PhD · AI学术训练营 的「AI学术工作台」桌面版：工作台里的每个按钮都是「执行」，点一下，你自己电脑上的 Codex 就把这一步做完，产出直接存进你的论文项目文件夹。

- **下载**：在右侧 [Releases](https://github.com/qiaomiaojoe/ai-academic-app/releases) 里找最新的 `app-v…`，Mac（Apple 芯片）下 `.dmg`，Windows 下 `.zip`。
- **用之前**：电脑上要装好 ChatGPT（或 Codex）并登录。智能在你自己的 Codex 里，软件不含模型、不用 API key。
- **更新**：装好以后，工作台和执行面板的更新会自动下载，在面板里点「立即更新」即可。

这个仓库只存放安装包和更新包，供软件自动下载；不接受 issue 和代码提交。有问题请在训练营群里找老师。
